# Task 1 — Basics of Web Development

Internship task submission for the **ApexPlanet Web Development Internship** (HTML, CSS & JavaScript track).

## 🔗 Overview

A small, single-page introduction site built to demonstrate foundational HTML structure, CSS styling, and JavaScript interactivity — the core requirements of Task 1.

## ✨ Features

- **Hero section** — name, role, and a short intro
- **"What I'm learning" section** — HTML, CSS, and JavaScript overview
- **About section** — profile photo and program details, with the ApexPlanet internship banner
- **Interactive greeting** — a button that triggers a randomized `alert()` message, plus an on-page confirmation using `aria-live` for accessibility
- **Links section** — GitHub, LinkedIn, and email
- **Fully responsive** design (mobile-friendly via media queries)
- Respects `prefers-reduced-motion` for accessibility

## 🛠️ Tech Stack

- HTML5 (semantic markup)
- CSS3 (custom properties, Flexbox, Grid, Google Fonts — Fraunces, Inter, JetBrains Mono)
- Vanilla JavaScript (no frameworks or libraries)
